## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Bun`, `Burger`, `Ingredient`, `Database`

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты, разделенные по классам. Например, `bun_test.py`, `burger_test.py` и т.д.

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

>  `$ pytest --cov=praktikum --cov-report=html`

# Файл tests.py:
# 1. Тест на инициализацию (test_burger_init): Проверяется, что булочки и ингредиенты изначально отсутствуют.
# 2. Тест добавления ингредиента (test_add_ingredient): Используется параметризованный тест для проверки добавления разных ингредиентов.
# 3. Тест удаления ингредиента (test_remove_ingredient): Проверяется удаление ингредиента по индексу.
# 4. Тест расчёта цены (test_get_price): Параметризованный тест для разных булочек и ингредиентов.
# 5. Тест печати чека (test_get_receipt): Проверяется формат чека. Этот тест проверяет, что метод get_receipt корректно формирует чек для бургера с несколькими ингредиентами.
# 6. Тест перемещения ингредиента (test_move_ingredient): Проверяется перемещение ингредиента в списке.
# 7. Тест test_set_buns проверяет установку разных типов булочек и убеждается, что цена булочки корректно учитывается в общей цене бургера.

# Файл conftest.py содержит определения фикстур для тестирования, которые обеспечивают необходимые объекты для тестов. В данном случае определяются три фикстуры:
# burger() — возвращает новый экземпляр класса Burger. Это позволяет каждому тесту иметь «чистый» экземпляр бургера без необходимости создавать его вручную в каждом тесте.
# ingredient() — возвращает объект Ingredient с заранее заданными параметрами («Tomato», «vegetable», 10). Это упрощает создание ингредиента для тестируемых сценариев.
# bun() — возвращает экземпляр Bun с указанными параметрами («Classic Bun», 20). Аналогично предыдущим фикстурам, это обеспечивает стандартизацию объекта булочки для тестов.
# Фикстура mock_ingredient создаёт моковый объект, имитирующий поведение объекта класса Ingredient.
# Фиктура mock_bun аналогично создаёт моковый объект для класса Bun.
